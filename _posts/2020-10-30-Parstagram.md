## Overview

Parstagram is an Instagram clone built with a custom Parse backend.  
The app allows users to post photos, view a global feed of photos, and add comments.

---

## Features

- Users can sign up to create a new account  
- Upload photos with captions  
- View a global feed of all user posts  
- Add and view comments on posts
